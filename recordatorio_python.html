Loops

What is a Loop?

A loop repeats a block of code multiple times. Python has two main loop types: for and while.

for Loop — Syntax

python
for variable in sequence:
    # code block

# Iterate a list
fruits = ['apple', 'mango']
for fruit in fruits:
    print(fruit)
using range()
for i in range(1, 6):
    print(i)  # 1 2 3 4 5

# With step
for i in range(0, 10, 2):
    print(i)  # 0 2 4 6 8

while Loop

python
count = 1
while count <= 5:
    print('Count:', count)
    count += 1
⚠️ Always update the variable inside while — otherwise it runs forever (infinite loop)!
else with loop
for i in range(3):
    print(i)
else:
    print('Done!')

break & continue

break — exit loop
for i in range(10):
    if i == 5:
        break
    print(i)
# prints 0 1 2 3 4
continue — skip iteration
for i in range(6):
    if i == 3:
        continue
    print(i)
# prints 0 1 2 4 5

Nested Loops

multiplication table
for i in range(1, 4):
    for j in range(1, 4):
        print(i, 'x', j, '=', i * j)
✅ Nested loops are fine for small data (tables, patterns, grids). For very large data they get slow (O(n²)), so consider list comprehensions or itertools.product.
✅ Tip: Use enumerate() to get index + value: for i, val in enumerate(items):

If Condition

What is an If Statement?

Conditional statements let your program make decisions based on whether a condition is True or False.

if / elif / else

python
marks = 75
if marks >= 90:
    print('Grade: A')
elif marks >= 75:
    print('Grade: B')
elif marks >= 60:
    print('Grade: C')
else:
    print('Grade: F')
# Output: Grade: B

Logical Operators

and / or / not
age = 20
has_id = True

# and — both must be True
if age >= 18 and has_id:
    print('Entry allowed')

# or — at least one True
if age >= 18 or has_id:
    print('May enter')

# not — reverse condition
if not has_id:
    print('No ID!')

python
num = 15
if num > 0:
    if num % 2 == 0:
        print('Positive Even')

        print('Positive Odd')

Ternary (One-line if)

python
# value_if_true if cond else value_if_false
x = 10
result = 'Even' if x % 2 == 0 else 'Odd'
print(result)  # Even

# Membership check
name = 'Raj'
if name in ['Raj', 'Priya']:
    print('Found!')

What is File Handling?

File handling lets you create, read, write, and manage files using Python’s built-in open() function.

File Modes

ModeMeaningCreates file?Overwrites?
'r'Read (default)NoNo
'w'WriteYesYes
'a'AppendYesNo
'x'Create (error if exists)YesNo
'r+'Read + WriteNoNo
'rb'Read binaryNoNo

Writing a File

recommended — with statement
with open('data.txt', 'w') as f:
    f.write('Hello, Python!\n')
    f.write('File handling!\n')
# File closes automatically
✅ Always use with — it auto-closes the file even if an error occurs!

Reading a File

python
with open('data.txt', 'r') as f:
    # Entire file as string
    content = f.read()

    # All lines as list
    lines = f.readlines()

# Loop through lines (efficient)
with open('data.txt') as f:
    for line in f:
        print(line.strip())

Append to File

python
with open('data.txt', 'a') as f:
    f.write('New line!\n')
# Does NOT delete existing content

Check File Exists

python
import os

if os.path.exists('data.txt'):
    print('File found!')
else:
    print('Not found!')

# Delete a file
os.remove('data.txt')

CSV File Handling

write csv
import csv

with open('students.csv', 'w',
          newline='') as f:
    w = csv.writer(f)
    w.writerow(['Name', 'Mark'])
    w.writerow(['Raj', 85])
read csv
import csv

with open('students.csv') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
# ['Name', 'Mark']
# ['Raj', '85']

Functions

What is a Function?

A function is a reusable block of code that performs a specific task. Functions help avoid repetition and keep code clean and organized.

Define & Call

python
def greet():
    print('Hello!')

greet()  # Output: Hello!

Parameters & Default Values

python
def greet(name='World'):
    print('Hello,', name)

greet()         # Hello, World
greet('Priya')  # Hello, Priya

return Statement

python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # 8

# Return multiple values
def min_max(lst):
    return min(lst), max(lst)

lo, hi = min_max([3, 1, 7, 2])  # 1, 7

*args & **kwargs

*args — variable positional
def total(*args):
    return sum(args)

print(total(1, 2, 3))     # 6
print(total(10, 20, 30))  # 60
**kwargs — variable keyword
def info(**kwargs):
    for k, v in kwargs.items():
        print(k, ':', v)

info(name='Raj', age=21)

Lambda Functions

anonymous one-line functions
square = lambda x: x ** 2
print(square(5))   # 25

add = lambda a, b: a + b
print(add(3, 4))   # 7
common use — sort with key
students = [
    ('Raj', 85),
    ('Priya', 92),
    ('Arun', 78)
]
students.sort(key=lambda x: x[1])
# Arun(78), Raj(85), Priya(92)

Scope — Local vs Global

python
x = 10   # Global variable

def show():
    x = 99   # Local — different from global x
    print(x)  # 99

show()
print(x)   # 10 (global unchanged)

# Use 'global' to modify global variable
def change():
    global x
    x = 50

change()
print(x)   # 50
✅ Best Practice: Avoid global variables. Pass values via parameters and return results instead.
